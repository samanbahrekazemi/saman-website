# Personal Portfolio & CV

> Minimalist, responsive personal portfolio and CV website built with vanilla HTML, Tailwind CSS, and Lucide icons — hosted on GitHub Pages.

![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Hosted-success?style=flat-square&logo=github)

---

## ✨ Features

- 🌗 **Dark/Light Mode** — Toggle themes; preference saved in localStorage.
- 📄 **Integrated CV** — Full resume summary, skills, and education.
- 🎨 **Stone Color Palette** — Clean, neutral, professional design.
- 📱 **Fully Responsive** — Optimized for all screen sizes.
- ⚡ **Performance-First** — Lightweight, no build tools, CDN-based.
